## S01｜0:00–0:03｜B · M4｜黑场云眼浮现

- **主资产**：`03_assets/cards/m4_engraving_eye_angled.png`（裁近景用）＋ `03_assets/textures/paper_env_black.jpg`
- **辅助**：`m4_engraving_ouroboros_angled.png`（第 3 层视差，低透明度）
- **构图**：黑场满版；云眼占画面 62%，中心略偏上 8%；四周留 18% 纯黑呼吸区。
- **运镜**：3%/s 匀速推近；5 层视差（黑底 0 / 云 0.2 / 眼 0.45 / 蚀刻卡 0.7 / 颗粒 1.0）。
- **动作**：0.0–1.2s 云眼从黑中"显影"（亮度 0→100%，非线性）；1.2s 瞳孔一次收缩（1.06→0.94，0.6s）；2.4s 停止推镜，留 0.6s 静止。
- **文字计划**：无。
- **转场**：入 = 黑场起幅；出 = 叠化到 S02（0.2s）。
- **声音**：次低频 38Hz 渐入（-24dB → -18dB）；无高频。
- **验收**：V01/V03/V11；M4 密度 35–55%；不得出现金粉或发光。

## S02｜0:03–0:06｜B · M4｜缎带铭文特写

- **主资产**：`m4_engraving_eye_angled.png` 的缎带局部（重裁 60% 放大）＋ `paper_bone.jpg`
- **构图**：铭文带占画面宽 84%，水平居中；上下各留 12% 黑。
- **运镜**：固定机位，0.3s 后 ±0.5% 呼吸式微推（不要循环推）。
- **动作**：铭文自左向右"油墨压印"逐字显现（0.9s，压印位移 ≤0.4mm，回弹 0.15s，禁止发光/金粉）；末帧 0.3s 完全静止。
- **文字计划**：缎带内后期排 `THE ALL-SEEING EYE`（IM Fell English SC，7–9pt 等效，字距 +4%）；下沉一行小字 `TRUE SIGHT GOES BEYOND VISION`（6pt）。
- **转场**：出 = 墨渗（接 S03）。
- **声音**：石头混响 + 极轻纸纤维摩擦；-20dB。
- **验收**：V05 文字不压线；V06 无 AI 文字；M4 字体只此一种。

## S03｜0:06–0:07｜转场｜墨渗露出粉纸

- **资产**：`paper_env_black.jpg` → `paper_blush.jpg`；遮罩用 `03_assets/textures/paper_blush.jpg` 的纤维通道。
- **动作**：0.5s turbulent displace（强度 18，尺度 40），黑色从画面右下向左上"渗开"；最后 0.2s 粉纸全亮。
- **转场**：出 = 硬切 S04 第一张卡（利用明度差做视觉重音，本片仅此 1 次光差跳切）。
- **声音**：撕裂纸声（0.35s，-16dB）+ 低频尾音收。
- **验收**：过渡不出现彩色光效/发光边缘。

## S04｜0:07–0:11｜A · M1｜M1 三连快抽

- **主资产**（按序）：`m1_07_get_shit_done.png` → `m1_02_band_aid_whisperer.png` → `m1b_06_tears_are_power.png`
- **构图**：卡占画面高 72%，水平居中；卡底边在画面 82% 处；背景 `paper_page_white.jpg` 带 0.35mm 接触阴影（刚性，不软）。
- **运镜**：固定机位；抽牌用 2.5D 位移（z 轴 0→-40mm 再落位），不是缩放。
- **动作**：每张 0.9s 抽出 + 0.12s 落位停顿 + 0.35s 翻正；第二张从右下入、第三张从左下入（方向交替）。
- **文字计划**：标签已印在卡上（资产自带），**不再加字**；字距检查 8–12%。
- **转场**：卡与卡硬切（不出转场）；末张停留进 S05。
- **声音**：纸声 ×3（每张 0.18s，-14dB）+ 轻铃（第三张落位时 -22dB）。
- **验收**：R11 单主体；R26 平面刚体（卡不弯）；A 单卡 ≥1.2s（本镜 3 张共 4s，每张 1.33s）。

## S05｜0:11–0:15｜A · M1｜泪眼停留 + 双卡滑入

- **主资产**：`m1b_06_tears_are_power.png`（停留）＋ `m1_08_fearless.png`、`m1_03_ceo_babe.png`（滑入）
- **构图**：主卡居中偏左 6%；右侧 2 张卡以 30° 扇形叠放，仅露 55%。
- **运镜**：固定；主卡 0.5mm 悬浮（正弦 4s 周期）；滑入卡为刚性平移（无旋转动画）。
- **动作**：0–1.2s 主卡停留（呼吸）；1.2–2.4s 双卡从右侧滑入（0.55s/张，ease-out）；2.4–4.0s 全部静止 1.6s（"呼吸"≥1.2s）。
- **文字计划**：主卡标签字距 8%→12% 微调（0.4s）；不新增文字。
- **转场**：出 = 叠化到 S06（0.3s）。
- **声音**：纸声 + 女声低语（气声，不含词义，-26dB）。
- **验收**：R13 正面性（不出现卡背）；三卡不重叠主体 >15%。

## S06｜0:15–0:19｜A · M2｜大牌翻面 The Fool → The Empress

- **主资产**：`m2_the_fool.png` → `m2_major_02.png`
- **构图**：单卡占画面高 78%，居中；背景 `paper_mauve.jpg` 满版（M2 舞台）。
- **运镜**：固定机位；Y 轴翻面 0.6s（前 0.25s 加速、后 0.35s 减速），翻面中卡身悬浮 ±2°。
- **动作**：0–0.6s 翻面；0.6–2.2s 停留（The Fool）；2.2–2.8s 换卡（硬切+0.2s 白闪≤6% 亮度）；2.8–4.0s 停留（The Empress）。
- **文字计划**：无新增；检查罗马数字/手写标题已在资产内且未被裁切。
- **转场**：出 = 翻到背面瞬间黑场硬切 S07（0 帧黑场，用运动模糊遮住）。
- **声音**：低频 pulse（60Hz，每 0.8s 一次，-24dB）。
- **验收**：M2 卡纸 `pale-rose`/舞台 `mauve`；绯红线唯一；不得出现金/黑。

## S07｜0:19–0:22｜B · 黑场章节卡｜XXVI + 云眼

- **资产**：`paper_env_black.jpg` + `m4_engraving_eye_angled.png` 局部（云眼）+ 后期排版罗马数字。
- **构图**：黑场；云眼占 38% 居中偏上；罗马数字 `XXVI` 在画面下 12% 处，居中。
- **运镜**：卡从黑中浮起 4%/s（z 轴 -60mm→0），仅 1 层。
- **动作**：罗马数字逐笔"刻"出（1.0s，线宽 0.10mm 等效）；云眼保持静止；末 0.5s 静止。
- **文字计划**：`XXVI`（EB Garamond SC，48pt 等效，字距 +6%，骨白 `bone`）。
- **转场**：出 = 硬切 S08（明度重音，本片第 2 次也是最后 1 次）。
- **声音**：次低频 32Hz，-20dB；无音乐。
- **验收**：V04 文字不发光；黑场纯度（不出现灰雾，允许 ≤5% 颗粒）。

## S08｜0:22–0:26｜A · M1｜M1 三连硬切

- **主资产**（按序）：`m1b_09_karma_is_a_bitch.png` → `m1_06_namaste_bitches.png` → `m1b_08_nostalgia_overload.png`
- **构图**：三张同机位、同大小（占高 74%），只用硬切，不做运动。
- **运镜**：固定。
- **动作**：每张 1.3s；切点落在上一张"静止满 0.4s"之后；每张入场 0.12s 的 1px 抖动（纸的"落桌"感）。
- **文字计划**：无新增；三张标签均为资产自带。
- **转场**：出 = 硬切 S09。
- **声音**：节奏加快：纸声 ×3（-12dB）+ 短 tick ×3（-20dB）。
- **验收**：A 单卡 ≥1.2s；三张不得同色系撞车（本组为 C1 默认三张，允许）。

## S09｜0:26–0:30｜A · M3｜金印 KNOWING #26 特写

- **主资产**：`m3_knowing_26.png`
- **构图**：卡占画面高 82%，居中；背景 `paper_rose.jpg` 满版、比卡暗 3%。
- **运镜**：固定 + 2% 微推（末 1s 停）。
- **动作**：金边逐段自绘（2.0s：先外框 → 四角 → 号牌 → 内框）；射线逐条绘出（0.8s，stagger 60ms）；2.0–4.0s 完全停格。
- **文字计划**：标签 `KNOWING` 已在卡内（白色几何无衬线，字距 +20%）；不新增。
- **转场**：出 = 叠化到 S10（0.4s）。
- **声音**：铃声上行（3 音，-20dB）；金线绘出时极轻"刻刀"声。
- **验收**：金=哑光（无金属高光）；M3 双框/角花/号牌齐全；密度 18–25%。

## S10｜0:30–0:34｜A/B｜泪眼 ↔ 全视之眼叠化

- **主资产**：`m1b_06_tears_are_power.png` ↔ `m4_engraving_eye_angled.png`（同构图：眼居画面中心，泪向下）
- **构图**：两图同大小同中心；A 粉底 → B 黑底。
- **运镜**：固定；叠化用纸纹擦除遮罩（横向，0.35s），不是普通 opacity 叠化。
- **动作**：0–1.2s A 停留；1.2–1.55s 纸纹擦除到 B；1.55–2.8s B 停留（眼不眨）；2.8–3.2s 擦回 A（更快，0.25s）；3.2–4.0s A 停留。
- **音效**：双声部叠合（纸声 + 石头混响），-18dB。
- **验收**：R25 版本同源（两图同构图）；不得出现彩色过渡；擦除边缘必须是纸纤维。

## S11｜0:34–0:38｜A · 品牌层｜品牌页 + 三卡

- **主资产**：`00_reference/reference_07_brand_page.jpg`（品牌页原件；品牌层版式直接引用，生产稿的插图/字标用 `03_assets/logo/` 的 SVG 重排）＋ `paper_page_white.jpg`

- **运镜**：固定；卡组从下往上落位 20mm（0.5s，ease-out），标题淡入 0.4s。
- **文字计划**：标题 `AN ENTIRELY ORIGINAL DECK OF CARDS`（Playfair Display 500，48–60pt，深梅 `brand-plum`，居中）；字标 `NOT TAROT` 置于底部安全区（宽 ≥ 卡宽 28%）。**全部后期排版**。

## S12｜0:38–0:42｜A · M1 变体｜三色并置

## 9:16 竖屏衍生规则

1. 镜头顺序、时长、系统配比**完全不变**，只重构图。
2. 卡占画面宽度 76%（不是高度）；文字/标签区统一在画面下 18%。
3. B 段（S01/S02/S07/S13）改全屏黑场，去掉多层视差（性能与可读性）。
4. S11 品牌页改**上下堆叠**：心形插图在上 40%，字标居中，三卡在最下 30% 横向并排（每卡宽 26%）。
5. S12 变体三卡改**纵向三连**（各高 26%，间距 4%）。
6. 所有文字安全区加大：左右 ≥8%，上下 ≥10%。
