## 0. 一页摘要（给决策者）

你提出的五个问题，我们判断**不是"再做好一点"的问题，而是结构问题**。v3 的改动全部是结构性的：

| 你的原话 | 我们判断的根因 | v3 的结构性修改 |
|---|---|---|
| 视觉张力太差 | 所有元素等大、居中、均匀分布，画面没有"层级" | **尺度语法**：每镜一个 0.65–0.95 画高的"巨物" + 一个 0.15–0.30 的次体 + 一个 ≤3% 的强调点；极端留白 ≥50% |
| 各内容衔接不和谐 | 转场靠"整场透明度交叉淡化"，两场只是叠在一起 | **转场全部改为"动作驱动"**：同一根线接续、一滴墨吃满、纸张撕开、符号盖印。每一场都从上一场的"物理后果"里长出来 |
| 线条错位 | 位图缩放 + 拼贴，线宽与位置都在漂 | **单线系统 + 矢量化**：所有母题用 vtracer 转 SVG，线宽统一三档（0.18/0.12/0.08mm 等效），放大 4 倍不糊、不错位 |
| 没有呼吸感 | 每镜等长、信息密度恒定，没有停顿与强弱 | **呼吸结构**：45s 分 4 个呼吸段，插入 3 个 0.4–0.8s 的"几乎静止"呼吸点（5.2–5.6s / 20.8–21.4s / 40.0–40.8s），呼吸点前后各有一个加速段 |
| 图标太小 | 图标被关在卡里，卡只有 6% 画面 | **拆卡**：图标从纸卡拉出、裸置为 0.45–0.90 画高的主体；卡只在需要"抽卡"语义时出现，且允许符号冲出卡框 |
| 三张参考图只是被"贴"进来 | 参考图当成卡片素材用，而不是当成"语言" | **拆解—重组**：三张图拆成 6 类元素（器官/面孔/蚀刻云/铭文缎带/罗马数字/边框），按解剖图版逻辑重新排版，原图不再整张贴入 |

同时，v3 保留你上一轮定下的 7 幕叙事骨架（心脏诞生 → 符号释放 → 符号世界 → 收缩成卡 → 连抽六卡 → 聚合图腾 → 品牌揭示），只是把每一幕的**画法**换掉。

### 2.2 重组规则（三条）

1. **一镜一器官**：每个镜头只允许一个"主器官"（眼/心/手/骷髅/蝶/花…），其余元素都是它的"回声"（缩小 20–40%、降透明度 30–60%、或只露出局部）。
2. **卡片是容器，不是画面**：卡出现时占画面 ≤22%；符号必须比卡大，可冲破卡框。全片 ≥40% 的镜头没有卡。
3. **原图不复现**：任何参考图整张出现时，必须满足"裁切 + 去原文字 + 换成本片墨色"三件事，否则不许用。

## 3. 方向 A（主推）：ONE INK / 一滴墨的转世

**一句话**：一滴墨落下，变成一根线；线画出一颗心；心裂开，放出所有符号；符号长成一个世界；世界被一滴墨盖住，黑里裂出六张卡；六张卡合成一个金色图腾；图腾最后收成一根线，写下品牌。

**世界观**：全片只有一个"实体"——墨。它可以是滴、是线、是心、是眼、是云、是卡、是图腾。所有转场都是这个实体的**相变**，不是剪辑。这是"衔接不和谐"的根治方案：观众看到的是同一个东西在变形。

**七幕（与上一轮骨架对齐，画法全换）**

| 幕 | 时间 | 内容 | 视觉重点（唯一） | 呼吸 |
|---|---|---|---|---|
| 01 心脏诞生 | 0.0–8.0 | 墨滴 → 线 → ECG → 心 | 心（0.7 画高，出血下缘） | 5.2–5.6 停 |
| 02 符号释放 | 8.0–14.0 | 心裂，符号喷出，18 符号绕心成环 | 裂口（0.5 画高）→ 符号环 | 无 |
| 03 符号世界 | 14.0–22.0 | 巨眼睁开；蚀刻云与阿卡纳人影组成世界 | 巨眼（0.9 画高，出血上缘） | 20.8–21.4 停 |
| 04 收缩成卡 | 22.0–24.5 | 一滴墨淹满画面（全片唯一黑场），黑裂成卡骨架 | 黑（100%） | 黑场即呼吸 |
| 05 连抽六卡 | 24.5–33.5 | 六卡依次抽出，每卡 1.5s，符号冲卡 | 当前卡符号（0.6 画高） | 每卡末 0.15s 微停 |
| 06 聚合成图腾 | 33.5–40.0 | 六符号飞向 12 圆位，金曼陀罗成形 | 图腾（0.8 画高） | 38.8–39.3 微停 |
| 07 品牌揭示 | 40.0–45.0 | 图腾收成一根线 → 线写成字标 | 字标（0.35 画宽） | 40.0–40.8 白呼吸 |

### 3.1 关键镜头的"压迫感"设计

- **S01 墨滴**：画面 92% 是空纸；墨滴只有 0.06 画高，但它落下时**整个画面跟着缩一下**（0.3% 的相机推拉），观众会"感觉到"重量。
- **S05 巨眼**：眼白占满画面，瞳孔偏左 8%，右边出血；虹膜的蚀刻线用 0.08mm 细线，眼睑用 0.18mm 粗线——**粗线定形，细线给密度**。
- **S08 第一张卡**：卡从黑场里"被撕出来"，先出现的是符号（0.6 画高），卡框 0.4s 后才补上——**符号先于容器存在**，这是 v3 的核心视觉观点。
- **S12 图腾**：12 个符号不是"排排坐"，而是从画面外飞入、在圆周上**撞停**（over-shoot 8% 再回弹），每一次撞击画面抖 2px。

## 4. 方向 B（备选）：EXQUISITE CORPSE / 拆解剧场

**一句话**：把三张参考图彻底拆成"解剖标本"，用 19 世纪医学图版的方式重新排版；画面像一本被拆开的书，每一页都是一个器官的处刑现场。

- 视觉：骨白线稿 on 环境黑；四宫格图版（见 `B1_v3.jpg`）；罗马数字、图版编号、解剖标注线；符号之间用"标本钉"和"缝合线"连接。
- 转场：硬切 + 纸撕（T3）+ 图版翻页，不用墨渗。
- 适合：如果客户想要"更狠、更冷、更像地下出版物"的版本；也适合作为方向 A 的 22.0–24.5s 黑场插入段（A 的主体 + B 的黑场四宫格 = 最强张力点）。
- 风险：信息密度高，45s 内不宜超过 8s；品牌温度低，结尾需要一次"回温"（金色图腾）才不冷场。

## 5. v3 视觉语法（新版 12 条，优先级高于旧版）

| 编号 | 规则 | 原因 | 正确 | 错误 |
|---|---|---|---|---|
| V3-01 | 每镜只有一个"压倒性重点"（≥0.6 画高） | 张力来自层级，不来自元素数量 | 巨眼占 90%，其余元素 ≤15% | 六卡一样大、均匀排开 |
| V3-02 | 单一墨色：莓红 #8F2C3B on 奶油 #FAF2EC | 一墨到底，符号才像"同一个实体" | 全片 90% 镜头只有墨色 + 纸色 | 每幕换一种颜色 |
| V3-03 | 全片只允许一次黑场（22.0–24.5） | 黑是标点，不是背景；用一次才重 | 黑场前后各留 0.3s 纯黑 | 每个转场都闪黑 |
| V3-04 | 极端留白：每镜 ≥45% 画面是空的 | 呼吸感 = 空的比例，不是慢的速度 | 墨滴镜 92% 空 | 满屏符号 |
| V3-05 | 禁止整场透明度淡化 | 淡化让两场"并列"，动作让两场"因果" | 线接续、墨渗、撕纸、盖印 | 交叉溶解 |
| V3-06 | 线条三档：0.18 / 0.12 / 0.08mm 等效 | 线宽是"音量"，三档够用，四档就乱 | 外轮廓 0.18，结构 0.12，密度 0.08 | 全片一种线宽 |
| V3-07 | 图标必须出卡：符号 ≥0.45 画高，可冲出卡框 20–40% | 卡是容器，符号是主角 | 虎头冲出卡顶 | 图标缩在卡里 |
| V3-08 | 卡只作容器：全片 ≥40% 镜头无卡 | 观众记住的是符号，不是卡 | 巨眼、心、世界段无卡 | 每一镜都举着卡 |
| V3-09 | 文字全片 ≤3 句 + 6 卡名 + 1 字标 | 文字是钉子，不是解说 | EVERYTHING MEANS SOMETHING. / A WORLD OF SYMBOLS. / BECOME. | 每镜一行字幕 |
| V3-10 | 运动只允许：飘、长、转、压、撕、聚合；禁止弹跳/挤压拉伸卡通风 | 线稿是"纸上的东西"，运动要像纸与墨 | 符号像墨一样流过去 | 卡片 Q 弹 |
| V3-11 | 每个转场必须回答"什么变成了什么" | 衔接不和谐的根因是"没有因果" | 心裂 → 符号（同一动作的两个阶段） | 淡入下一场 |
| V3-12 | 品牌最后 3 秒才出现，且 43.5s 后完全静止 | 品牌揭示是句号，不是水印 | 42.0s 字标落位，43.5s 静止 | 全片角落挂 logo |

## 7. 交互设计（HTML 播放器版）

线性 MP4 仍然交付（投放用），但网页版承担"可玩"的部分——**交互不是加特效按钮，而是让观众亲手完成"抽卡"这个核心动作**。

| # | 交互 | 触发 | 反馈 | 降级（移动端 / MP4） |
|---|---|---|---|---|
| I1 | 拖墨滴开始 | 首屏一颗墨滴，拖动它落到纸上 | 墨滴落入 → 全片开始；不拖则 5s 后自动落 | 点击开始 |
| I2 | 瞳孔跟随 | 鼠标/手指移动 | 巨眼瞳孔向指针偏移 ≤6px，眼睑微颤 | 自动缓慢游移 |
| I3 | 点卡翻面 | 点击六卡任意一张 | 卡翻面显示卡名 + 一句卡义（如 "FEARLESS — 恐惧是你还活着的证据"） | 卡名自动浮现 |
| I4 | 章节墨点 | 右下角 7 个墨点 | hover 显示章节名；点击跳到该幕 | 进度条 |
| I5 | 按住呼吸 | 长按画面（或空格） | 全片减速到 0.35×，呼吸点延长，墨线微微起伏 | 无 |
| I6 | 滚轮抽卡 | 在第五幕滚动 | 六卡随滚动依次抽出；反向滚动可"放回" | 自动播放 |
| I7 | 抽你自己的卡 | 结尾 42s 后点击字标 | 从 68 符号中随机抽 1 张，生成"你的卡"（可截图分享） | 随机闪一张卡 |
| I8 | 声音反馈 | hover 卡/符号 | 极轻的纸声/墨点声（≤ -30 LUFS），不打扰主音轨 | 静音 |

技术实现：沿用现有单文件 HTML 播放器架构（`07_final/NOT_TAROT_45s_cinematic.html` 已验证可用），v3 全部母题改为 SVG，时间轴用 Web Animations API；MP4 用 Playwright 逐帧截图 + ffmpeg 编码（现有 `capture_cinematic.py` / `encode_films.py` 可直接复用）。

## 10. 需要你确认的三件事

**Q1｜方向**
- **A（主推）**：ONE INK / 一滴墨的转世 —— 单一实体相变，最连贯、最有呼吸感。
- **B（备选）**：EXQUISITE CORPSE / 拆解剧场 —— 最狠、最冷、图形张力最强。
- **A + B 混合（推荐）**：A 为主体，22.0–24.5s 黑场段用 B 的四宫格图版（约 2.5s），既有连贯性又有一次"解剖"暴击。

**Q2｜交互级别**
- **L1 线性**：只做 MP4，不做网页交互（最快，投放安全）。
- **L2 轻交互（推荐）**：网页版做 I1/I2/I3/I4/I7（拖墨滴、瞳孔跟随、点卡翻面、章节墨点、抽你的卡），其余保持线性。
- **L3 全交互**：I1–I8 全做，包括滚轮抽卡与按住呼吸（最惊艳，工期 +1 天，低端机需降级）。

**Q3｜黑场比例**
- v3 默认：全片仅 22.0–24.5s 一次黑场（2.5s）。
- 如果你想要"更重"：可把 14.0–17.5s 巨眼段也压成骨白线 on 黑（B 方向语言），黑场总时长 6s，风险是品牌温度下降。

> 回复格式建议：`A+B / L2 / 默认黑场` 这样一句话即可，我们按此进入生成。
