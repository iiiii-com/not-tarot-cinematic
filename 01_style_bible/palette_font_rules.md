# 01_style_bible · 色板与字体执行规则（Palette & Font Rules）

> 这是 `style_bible.md` 的"一页版执行卡"：做图/排版/动效时先看本页，细节再回主文档。  
> 规则编号与主文档一致（R01–R34、C1–C7）。**本页任何数值不得凭感觉改。**

## 2. 七组合法组合（卡面配色）

| 组合 | 卡纸 | 面板/舞台 | 墨线 | 用途 |
|---|---|---|---|---|
| C1 | `cream` | `blush` | `ink-berry` | M1 默认（约 70% 卡） |
| C2 | `cream` | `blush` | `lampblack` | M1-V2 黑墨变体（≤10%） |
| C3 | `cream` | `lilac` + `mint` 框 | `lampblack` | M1-V3 藕紫变体（≤10%） |
| C4 | `pale-rose` | `mauve` | `ink-crimson` | M2 大牌 |
| C5 | `rose` | `rose` | `ink-gold` | M3 金印 |
| C6 | `bone` | `env-black` | `lampblack` | M4 夜版 |
| C7 | `page-white` | — | `brand-plum` + `ink-berry` 插图 | 品牌层 |

**非法组合**：跨系统混色（M1 粉面板 + 金线 / M3 玫瑰卡 + 绯红线 / 品牌层出现金或黑场）；单张卡出现两个墨色（R02/R24）。

## 3. 线稿规则

| 线型 | 打印线宽 | 屏幕线宽（1080 高） | 用途 |
|---|---|---|---|
| 主线 | 0.18 mm | 2.6 px | 主体轮廓 |
| 结构线 | 0.12 mm | 1.7 px | 内部结构/转折 |
| 细节线 | 0.08 mm | 1.1 px | 排线、肌理、细毛 |
| 边界符 | 0.07 mm | 1.0 px | M3 边框/角花 |
| 缎带线 | 0.10 mm | 1.4 px | M4 铭文带 |

- 手绘抖动上限 **±0.3 px**（屏幕）；每 8–12 帧一次"boil"，只抖不跳。
- 线条两端收笔为**尖收**，不得圆头、不得发光、不得加投影。
- **零填充**：任何色块面积 >2mm² 都不允许，体积靠排线。

## 4. 排线 / 阴影规则

| 明度档 | 排线密度 | 覆盖率 | 交叉 |
|---|---|---|---|
| L0 高光 | 无 | 0% | — |
| L1 | 5–8 条/cm | 10–20% | 单组 45° |
| L2 | 8–12 条/cm | 25–35% | 45° + 135° 两组 |
| L3 | 12–16 条/cm | 35–45% | 两组 + 点刻 |
| L4 暗核 | 16–20 条/cm | 45–55% | 三组以内，禁止全黑 |

- 排线方向：主 45°，第二组 135°，**不出现水平/垂直排线**（会像 UI 网格）。
- 亮面留白 ≥40%；阴影一律排线，**禁止渐变、软笔刷、投影**。
- 点刻只用于 L3/L4，密度不超过 6 点/mm²。

## 5. 纸张与纹理

| 项 | 参数 |
|---|---|
| 纸底色 | 见颜色令牌；同一张卡只有一种纸色 |
| 纸纹 | 纤维 ≤0.3mm，噪点幅度 ≤±4/255，覆盖率 ≤12% |
| 做旧 | 无脏点、无折痕、无咖啡渍；仅允许极轻边缘暗角（≤3%） |
| 印刷 | 哑光 letterpress 压印感；金=哑光印金，不得金属高光 |
| 纹理文件 | `03_assets/textures/paper_*.jpg`（1024²，可裁切平铺） |

## 6. 卡牌比例与安全区

| 项 | 数值 |
|---|---|
| 成品尺寸 | 70 × 120 mm（1:1.714） |
| 出血 | 3 mm（73×123mm 画布） |
| 裁切线内安全 | 6 mm |
| 文字安全区 | 8 mm（标签距裁切线 ≥8mm） |
| 圆角 | R3 mm |
| 卡厚 | 0.35 mm（350gsm 近似） |
| 屏幕画布 | 1080×1851 px（300dpi 等效），主体居中 |
| 边框内缩 | M1 3mm / M2 4mm / M3 5mm / M4 6mm |

## 7. 字体

| 用途 | 字体 | 字重/字号 | 字距 | 备注 |
|---|---|---|---|---|
| 品牌大标题 | Playfair Display / Cormorant Garamond | 500–600 / 48–72pt | 0 | 只用于品牌层 |
| M1 标签 | EB Garamond / Cormorant | 500 / 8–10pt，全大写 | +8–12% | 标签位距底边 12mm |
| M2 标题 | Pinyon Script / Snell Roundhand | 400 / 18–22pt | +2% | 手写体只写标题，不写正文 |
| M2 编号 | EB Garamond SC | 400 / 10pt | +6% | 罗马数字居上 |
| M3 标签 | Jost / Futura PT | 400 / 8pt，全大写，白色 | +20% | 白几何无衬线 |
| M4 铭文 | IM Fell English SC | 400 / 7–9pt | +4% | 只出现在缎带内 |
| 中文 | Noto Serif SC（思源宋体） | 400–500 | 0 | 只用于品牌层副文 |

- 一卡最多 2 种字体（标题 + 编号/标签）；**不得 3 种以上**。
- 禁止：无衬线正文（除 M3 标签）、描边字、投影字、渐变字、艺术字变形。
- AI 生图**不生成文字**（R28/R33），只在画面留出文字区，排版由设计后期完成。

## 8. 密度预算

| 模式 | 墨覆盖率 | 元素数 | 留白 |
|---|---|---|---|
| M1 | 3–14% | 1 主符号 + 0–2 小符号 | ≥55% |
| M2 | 17–28% | 主体 + 边框 + 编号 + 标题 | 35–45% |
| M3 | 18–25% | 徽章 + 双框 + 号牌 + 标签 | 40–50% |
| M4 | 35–55% | 满版蚀刻 + 缎带 | ≤20% |
| 品牌层 | ≤8% | 插图 + 2–3 行字 | ≥65% |

## 9. 十二项硬性否决（V01–V12）

1. 出现渐变/投影/发光/霓虹/金属高光
2. 出现未登记的新颜色
3. 线条粗细混用超过三档
4. 出现填充色块（>2mm²）
5. 排线方向错误（水平/垂直）
6. 文字压在主体上 / AI 生成文字
7. 字体超过两种 / 出现描边字
8. 边框模式混用（M1 卡画 M3 金框）
9. 跨系统混色（A 卡出现 B 黑场）
10. 同一符号两次画得不一样（未复用母版）
11. 新增未登记符号（超出 68 符号 + 14 边界符）
12. 分辨率/出血/安全区不达标（<300dpi 或文字进 8mm 内）
